# TruckFood — Roadmap

**Version:** 1.0.0  
**Status:** Working roadmap  

The roadmap is deliberately phase-based. A phase closes only when its objectives and validation criteria are satisfied.

## Phase -1 — Discovery & Foundation

**Status:** In progress

Objectives:

- define the problem;
- define users and journeys;
- define product boundaries;
- identify critical data sources;
- identify licensing constraints;
- establish architecture principles;
- establish project governance;
- define MVP scope.

## Phase 0 — Architecture

Objectives:

- domain model;
- system boundaries;
- API boundaries;
- data ownership;
- map-provider abstraction;
- security model;
- observability model;
- deployment model.

## Phase 1 — Data Foundation

Objectives:

- database schema;
- locations;
- vehicle profiles;
- source/provenance model;
- trust/confidence model;
- initial seed/import strategy.

## Phase 2 — Backend / API

Objectives:

- authentication;
- location APIs;
- search APIs;
- reviews/community APIs;
- vehicle-aware data queries;
- administration capabilities;
- tests and security controls.

## Phase 3 — Mobile MVP

Objectives:

- authentication;
- map;
- search;
- location details;
- parking/food/service discovery;
- basic driver profile;
- community contribution;
- favourites.

## Phase 4 — Web & Administration

Objectives:

- public web experience;
- moderation;
- data administration;
- quality/trust tools;
- operational dashboards.

## Phase 5 — Truck Intelligence

Objectives:

- vehicle-aware restrictions;
- route-context analysis;
- restriction warnings;
- confidence-aware recommendations;
- parking and stop planning.

This phase is dependent on validated data quality and licensing.

## Phase 6 — Community & Trust

Objectives:

- confirmations;
- reports;
- reputation signals;
- trust scoring;
- freshness workflows;
- abuse prevention.

## Phase 7 — Growth & Commercialisation

Potential capabilities:

- premium features;
- featured businesses;
- partnerships;
- fleet tools;
- advertising where appropriate;
- professional services.

## Phase 8 — International Scale

Potential capabilities:

- multiple countries;
- languages;
- currencies;
- timezones;
- local regulations;
- regional data providers;
- international partnerships.

## Rule

No later phase should force implementation of an earlier assumption that has not been validated.
